# Дополнительные функции

Каждый файл `*.md` в этой папке — одна функция скилла: когда её применять и какие команды запускать.
Если просьба не подходит под разделы SKILL.md — посмотри здесь список файлов и прочитай подходящий.
Новые функции приходят с обновлением скилла (`python scripts/update.py`), ставить отдельно не нужно.

Формат файла: первая строка `# Название`, вторая — `Когда: …` (по каким просьбам), дальше — что делать и какие скрипты запускать.
