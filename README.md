# Скиллы ПТО для Claude

Два скилла для исполнительной документации:

- **pto-head** — начальник ПТО: сводка по команде — открытые замечания технадзора, статус актов по инженерам и от кого нет данных, история сдач.
- **pto-engineer** — инженер ПТО: скан рабочих папок (что подписано, что в работе), АОСР по 344/пр из журнала или описания, проверка актов, замечания технадзора с проверкой перед сдачей, реестры ИД и паспортов, опись, уборка дублей.

Проверки и расчёты делают скрипты на Python (только стандартная библиотека), а не модель.

## Что нужно

- Claude Code или Claude Desktop (вкладка Code). В веб-версии claude.ai скилл не видит Google Диск.
- Python 3.9+. Нет — `winget install -e --id Python.Python.3.12` (или скилл сам предложит).
- «Google Диск для компьютера» и общая папка команды «ПТО — Объект».

## Установка

### Если работаете в обычной вкладке «Чат» Claude Desktop

1. Скачайте `pto-chat.mcpb` со страницы последнего выпуска: https://github.com/Labazyan1/pto-skills/releases/latest
2. Дважды щёлкните файл. Claude Desktop откроет окно установки расширения.
3. В окне укажите имя, роль (инженер или начальник), папку команды «ПТО — …» на Google Диске и свои рабочие папки.
4. В обычном чате напишите «сводка по команде».

Нужен Python 3.9+. Обновляется само раз в день (скрипты и инструкции). Изредка, если меняется сама программа расширения, нужно поставить новый `pto-chat.mcpb` поверх.

### Если работаете в обычном чате без расширения (claude.ai в браузере, телефон)

1. Скачайте `pto-chat-skill.zip` со страницы последнего выпуска (ссылка выше).
2. На claude.ai: «Настройки» → «Возможности» (Capabilities) → включите выполнение кода и создание файлов → «Навыки» (Skills) → «Загрузить навык» → выберите архив. Навык действует во всех ваших чатах, в том числе на телефоне.
3. Работайте как обычно: загружайте файлы в чат. В конце задания скажите «собери выгрузку» — скилл соберёт архив с журналом чата, оригиналами загруженных файлов и результатами; скачайте его и перешлите.

Сводка по команде здесь недоступна (нет общей папки) — для них нужно расширение или вкладка Code. Обновление — загрузить новый архив поверх.

### Если работаете во вкладке Code (Claude Desktop или Claude Code)


Напишите Claude: «установи скилл pto-head с github.com/Labazyan1/pto-skills» (инженеру — pto-engineer). Или сами в PowerShell:

```powershell
irm https://raw.githubusercontent.com/Labazyan1/pto-skills/main/install.py -OutFile $env:TEMP\pto-install.py; python $env:TEMP\pto-install.py --install pto-head
```

Для Claude: скачать `install.py` из этого репозитория и выполнить `python install.py --install <скилл>` — он ставит папку скилла в `~/.claude/skills/<скилл>` без git. Затем откройте новый чат и напишите «покажи здание» (начальник) или «настрой скилл» (инженер): дальше скилл проведёт сам — проверит Python и Диск, начальнику создаст папку команды и даст текст для инженеров.

## Обновление и новые функции

Автообновление: раз в день скилл (вкладка Code — `update.py --auto`, расширение «Чата» — при запуске) сам проверяет GitHub и, если вышла новая версия, ставит её и пишет одной строкой, что нового. Ставится выпуск по тегу (не текущая ветка); настройки и данные обновление не трогает. Выключить: `python scripts/update.py --off` (в «Чате» — «выключи автообновление») — тогда скилл сам в сеть не ходит. Новые функции приходят с обновлением (папка `modules/`), что изменилось — в `CHANGELOG.md`.

Если компания не хочет зависеть от этого репозитория: сделайте форк (или скопируйте нужный выпуск к себе), поставьте из него и поменяйте `source.json` в папке скилла на свой репозиторий; обновления тогда приходят только оттуда, после вашей проверки.

## Как работает команда

1. Начальник создаёт папку на Google Диске («ПТО — ЖК Пример»; скилл делает это сам) и открывает её инженерам.
2. Инженеры добавляют её ярлыком в «Мой диск» — папка появляется на ПК.
3. У каждого инженера своя подпапка: акты, журнал, снимок рабочих папок, замечания. Чужие подпапки скилл не трогает, поэтому конфликтов синхронизации нет.
4. Начальник говорит «сводка по команде» — видит, что подписано, что на подписи и какие замечания открыты.

## Какие данные куда уходят

- Разработчикам скилла не передаётся ничего. Сетевые обращения в коде — только чтение с GitHub (raw.githubusercontent.com, codeload.github.com) для установки и проверки обновлений.
- Документы и запросы обрабатывает Claude — то есть Anthropic, по условиям вашей подписки. Хранит их Google Диск команды. Это два внешних сервиса: если в компании есть правила для ПД и коммерческой тайны, согласуйте их использование заранее.
- Начальнику скилл показывает только готовность: статус актов, замечания технадзора, когда инженер обновлял данные. Журнал запросов инженера к скиллу и список файлов его рабочих папок в сводку не попадают.
- При этом всё, что лежит в папке команды, технически видно каждому, у кого к ней доступ: акты, журнал запросов, список файлов (скан), замечания, имя и почта инженера. Инженеры узнают об этом при первом запуске. Доступ к папке давайте только своей команде.
- Выгрузка: по просьбе (и в расширении раз в неделю) скилл собирает архив `выгрузка_ПТО_<дата>.zip`: журнал, сводки чатов, тройки с оригиналами файлов, замечания. Архив кладётся в папку «_выгрузка» внутри папки команды (она на Диске начальника), хранятся последние 8 на человека; начальник может открыть эту папку, кому решит. Другая папка, в том числе чужая общая, добавленная ярлыком в «Мой диск»: `python scripts/export.py --папка "<путь>"`. Скилл архив никуда не отправляет: его видит тот, кому владелец папки открыл доступ.
- При настройке скилл меняет одну настройку Claude Code: история чатов хранится 10 лет вместо 30 дней (`cleanupPeriodDays` в `~/.claude/settings.json`, копия старого файла — `settings.json.bak-pto`). В выгрузку попадают сессии вкладки Code, где работал скилл, с вложениями.
- Скрипты ничего не удаляют; рабочие файлы инженеров скан только читает.

## Ограничения

Список устаревших норм — черновик, сверяйте с действующей редакцией. Статус «подписан» по файлам — догадка по имени и виду файла (скан). Готовые DOCX/PDF по форме, комплект ZIP, сверка с журналом работ и чертежами, план здания из чертежей — на платформе.
