# Скиллы ПТО для Claude

Два скилла для исполнительной документации:

- **pto-head** — начальник ПТО: «покажи здание» — корпуса и этажи по цветам (сдано, готово, не хватает, не начато) и чего ждём; доска «этажи × системы», открытые замечания технадзора, кто что сделал и от кого нет данных, история сдач.
- **pto-engineer** — инженер ПТО: скан рабочих папок (что подписано, что в работе), АОСР по 344/пр из журнала или описания, проверка актов, замечания технадзора с проверкой перед сдачей, реестры ИД и паспортов, опись, уборка дублей.

Проверки и расчёты делают скрипты на Python (только стандартная библиотека), а не модель.

## Что нужно

- Claude Code или Claude Desktop (вкладка Code). В веб-версии claude.ai скилл не видит Google Диск.
- Python 3.9+. Нет — `winget install -e --id Python.Python.3.12` (или скилл сам предложит).
- «Google Диск для компьютера» и общая папка команды «ПТО — Объект».

## Установка

Напишите Claude: «установи скилл pto-head с github.com/Labazyan1/pto-skills» (инженеру — pto-engineer). Или сами в PowerShell:

```powershell
irm https://raw.githubusercontent.com/Labazyan1/pto-skills/main/install.py -OutFile $env:TEMP\pto-install.py; python $env:TEMP\pto-install.py --install pto-head
```

Для Claude: скачать `install.py` из этого репозитория и выполнить `python install.py --install <скилл>` — он ставит папку скилла в `~/.claude/skills/<скилл>` без git. Затем откройте новый чат и напишите «покажи здание» (начальник) или «настрой скилл» (инженер): дальше скилл проведёт сам — проверит Python и Диск, начальнику создаст папку команды и даст текст для инженеров.

## Обновление и новые функции

Ставится выпуск по тегу (`v2026.11.21`), а не текущее состояние репозитория. Раз в день скилл проверяет, есть ли новая версия (читает файл VERSION с GitHub), и предлагает обновиться: сначала показывает, какие файлы изменятся, применяет только после вашего «да» (`python scripts/update.py`, затем `--yes`). Выключить проверку: `python scripts/update.py --off` — тогда скилл сам в сеть не ходит. Новые функции приходят с обновлением (папка `modules/`, это тоже инструкции для Claude), что изменилось — в `CHANGELOG.md`. Настройки и данные обновление не трогает.

Если компания не хочет зависеть от этого репозитория: сделайте форк (или скопируйте нужный выпуск к себе), поставьте из него и поменяйте `source.json` в папке скилла на свой репозиторий; обновления тогда приходят только оттуда, после вашей проверки.

## Как работает команда

1. Начальник создаёт папку на Google Диске («ПТО — ЖК Пример»; скилл делает это сам) и открывает её инженерам.
2. Инженеры добавляют её ярлыком в «Мой диск» — папка появляется на ПК.
3. У каждого инженера своя подпапка: акты, журнал, снимок рабочих папок, замечания. Чужие подпапки скилл не трогает, поэтому конфликтов синхронизации нет.
4. Начальник говорит «покажи здание» — получает `здание.html` и `доска.html` в папке команды.

## Какие данные куда уходят

- Разработчикам скилла не передаётся ничего. Сетевые обращения в коде — только чтение с GitHub (raw.githubusercontent.com, codeload.github.com) для установки и проверки обновлений.
- Документы и запросы обрабатывает Claude — то есть Anthropic, по условиям вашей подписки. Хранит их Google Диск команды. Это два внешних сервиса: если в компании есть правила для ПД и коммерческой тайны, согласуйте их использование заранее.
- В папке команды видно всем, у кого к ней доступ (начальнику — в первую очередь): акты инженеров, их журнал запросов к скиллу, список и пути файлов рабочих папок (скан), замечания технадзора, имя и почта инженера. Инженеры узнают об этом при первом запуске. Доступ к папке давайте только своей команде.
- Скрипты ничего не удаляют; рабочие файлы инженеров скан только читает.

## Ограничения

Список устаревших норм — черновик, сверяйте с действующей редакцией. Статус «подписан» по файлам — догадка по имени и виду файла (скан). Готовые DOCX/PDF по форме, комплект ZIP, сверка с журналом работ и чертежами, план здания из чертежей — на платформе.
